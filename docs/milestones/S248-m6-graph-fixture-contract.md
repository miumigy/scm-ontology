# S248 — Canonical Graph Fixture Contract

## Objective

Translate the M5 validation contracts into deterministic executable graph fixtures.

## Acceptance

- fixture schema is explicit
- canonical entities and relations are deterministic
- provenance is preserved
- expected reasoning results are declared
- vendor-specific semantics remain outside the canonical graph

## Boundary

S248 defines the fixture contract only. It does not yet implement a production graph store or enterprise connector.
