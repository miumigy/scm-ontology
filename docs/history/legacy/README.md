# Legacy Archive

This directory preserves **superseded development-era documents** that are no part
of the current product surface. They are retained for provenance and traceability
only. They describe early simulation, causal, transition-chain, and fixture design
that was superseded by the governed contracts in
[`docs/architecture/`](../../architecture/), [`docs/semantics/`](../../semantics/),
[`docs/operations/`](../../operations/), and [`docs/reference/`](../../reference/).

A short `Historical reference: …` note records the development identifier when one
was removed from the filename. These documents are **not** normative guidance for
v0.1.0. For the current product, start at the repository
[`README.md`](../../README.md) and [`docs/launch/`](../../launch/README.md).
