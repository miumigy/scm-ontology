# SCM Ontology v0.2 Release Candidate

v0.2 RC freezes the semantic and reasoning architecture established through S235.

## Frozen stack

Canonical Semantic Model → Canonical Graph → Query / Traversal → Constraints → Evidence / Provenance → Reasoning Result → Explanation / Confidence → Reasoning Policy → SCM Reasoning Patterns → External Adapters.

## RC invariants

1. Canonical ontology semantics remain independent of ERP/WMS/TMS/planning products.
2. Reasoning is read-only by default.
3. Inferred information is never promoted to canonical truth implicitly.
4. Evidence is provenance metadata, not ontology truth.
5. Confidence is derived metadata, not ontology truth.
6. Reasoning patterns reference canonical predicates; they do not define new canonical predicates.
7. Path constraints operate only on existing graph paths.
8. Explanations are deterministic projections of result/evidence state.
9. External adapters translate representations without redefining canonical semantics.
10. Regression tests are part of the release contract.

## Scope

v0.2 is a semantic/reasoning foundation release. It is not yet an enterprise integration product, AI agent, planner, optimizer, or autonomous graph-writing system.

After RC acceptance, implementation shifts toward SCM use-case validation and external-system mapping while preserving these invariants.
