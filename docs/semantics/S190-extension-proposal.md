# S190 — Governed Extension Proposal

S190 introduces an immutable proposal artifact that can only be created from an `ACCEPTED` governance decision.

```text
Extension Candidate
        ↓
Governance Decision
        ↓
ACCEPTED
        ↓
ExtensionProposal
```

The proposal is not an ontology mutation. It records the proposed predicate and endpoint types for a later, separately governed registry-application step.
