# Changelog

All notable public changes to SCM Ontology are documented here.

## [0.1.0] — Primary Launch

### Added

- First release-oriented public boundary for SCM Ontology and SCM OS Reference.
- Deterministic Primary Launch Golden Path.
- Machine-executable L5 primary-launch acceptance gate.
- Multi-source ERP + WMS + TMS reference convergence demo.
- Explicit primary-launch limitations and release checklist.
- English and Japanese launch documentation.
- Contributor guidance for post-launch development.

### Governance

- Canonical Truth remains an explicit governed boundary.
- Mapping, inference, projection, and ingestion do not implicitly mutate Canonical Truth.
- Provenance, history, uncertainty, authorization, and replay remain first-class invariants.
- AI/agents remain bounded reasoning/proposal providers rather than direct state mutators.

### Release boundary

This is a reference-quality OSS release. Production connectors, production HA/SLA, enterprise IAM/security certification, unrestricted autonomy, and large-scale operational guarantees are explicitly outside the v0.1.0 claim.

## Pre-0.1.0

The pre-release development history is preserved in the repository's milestone and contract documents for traceability. Those historical identifiers are not the public release numbering scheme.
